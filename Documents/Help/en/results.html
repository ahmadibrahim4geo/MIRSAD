Open a specific result in the table tab, select its layer/worksheet and navigate pages. Previews are read-only and do not execute macros or alter workbooks. GeoTIFF/lines can be displayed as context layers; PDF pages appear in the atlas tab. A preview is not a working point input unless explicitly imported/selected for that role.

The task log shows download/export/raster progress, elapsed time and cancellation. Downloads, GIS and file inspection run outside the UI process. Cancellation may wait for an active network request; it does not mean the button was ignored. Keep partial results and use a new project name for a rerun. Hybrid can reuse completed request cache with identical settings.

Removing a view does not delete its source file. Keep the _internal directory with MIRSAD.exe; it is part of the application. Installation/uninstallation preserves user projects stored outside the application directory.
