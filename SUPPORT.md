# Help and support / المساعدة والدعم

Start with the offline [Arabic manual](Help/MIRSAD_Help_AR.html), [English manual](Help/MIRSAD_Help_EN.html), or Windows CHM files in `Help/`. Download the whole repository ZIP for local use; GitHub's file view does not execute the interactive HTML manual. The same guide opens through Help/F1 in Desktop.

Use the repository's issue templates for a reproducible bug, a feature idea, or documentation corrections. Include the development version, host (ArcMap/Pro/Desktop), source, period, element and a small sanitized example. Report expected and actual values and their units. Do not attach credentials. A licensed native ArcGIS run or authenticated source download may require a separate environment that contributors do not have.

ابدأ بالدليل العربي أو الإنجليزي وملفات CHM المحلية. استخدم قوالب Issues للأعطال والأفكار وتصحيح التوثيق، مع الإصدار والمضيف والمصدر والفترة والعنصر ومثال صغير منزوع البيانات الحساسة. اذكر المتوقع والفعلي والوحدات. ملفات EXE والمثبت ليست ضمن مصدر Git؛ حالة نشر النسخة الثنائية موضحة في README.
