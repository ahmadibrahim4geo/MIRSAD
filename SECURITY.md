# Security / الأمان

Desktop is under development. The maintained source is the current default branch; no independent stable Desktop release has been approved yet. Native GIS libraries and external data services have separate update/support cycles.

Never attach passwords, CDS tokens, Earthdata credentials, personal station data or an unredacted project/log to an issue. Credentials belong in the masked runtime controls and must not be written to saved requests or Git. Use ordinary TLS verification.

For a vulnerability, use GitHub's private reporting option **if enabled** on this repository. If it is unavailable, open a minimal issue asking the maintainer for a private channel, without exploit details or secrets. This policy does not promise a response time or invent a support address. Ordinary bugs belong in the bug template.

لا تنشر كلمات المرور أو رموز الدخول أو بيانات المشروعات الحساسة في Issues. استخدم الإبلاغ الخاص إن كان مفعّلًا، وإلا اطلب قناة خاصة برسالة عامة موجزة بلا تفاصيل استغلال أو أسرار. لا تعطل حماية Windows أو التحقق من الشهادات لتجاوز عطل تشغيل.

See [Desktop boundaries and prior audit scope](MIRSAD%20Desktop/docs/development/SECURITY.md). A dependency audit is dated evidence, not a guarantee that the application is free of defects.
