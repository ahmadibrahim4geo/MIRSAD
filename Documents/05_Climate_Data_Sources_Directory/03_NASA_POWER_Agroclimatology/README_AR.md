# نموذج ناسا للمناخ الزراعي والطاقة المتجددة (NASA POWER / MERRA-2)

## 1. نبذة عامة
- **اسم المصدر البرمجي:** `NASA POWER API (Agroclimatology / MERRA-2)`
- **الهيئة المسؤولة:** الإدارة الوطنية للملاحة الجوية والفضاء الأمريكية (NASA)
- **المركز الرئيسي:** مركز لانغلي للبحوث (NASA Langley Research Center - LaRC)، هامبتون، فرجينيا.
- **مركز النمذجة العددية:** مكتب النمذجة والاستيعاب العالمي لناسا (GMAO).
- **النماذج العددية الأساسية:**
  - نموذج MERRA-2 (Modern-Era Retrospective analysis for Research and Applications, Version 2)
  - نموذج GEOS-FP-IT (Forward Processing for Instrument Teams) للأيام الحديثة
  - بيانات الأقمار الصناعية CERES FLASHFlux للإشعاع الشمسي والـ UV.

## 3. ما يستطيع هذا المصدر توفيره (القدرات ونقاط القوة)
1. **الإشعاع الشمسي والطاقة (المعيار العالمي الذهبي):**
   - الإشعاع الشمسي الكلي تحت كافة ظروف السماء (`ALLSKY_SFC_SW_DWN`) بدقة استثنائية.
   - الإشعاع المباشر (DNI) والإشعاع المنتشر والسماء الصافية.
   - مؤشر الأشعة فوق البنفسجية اليومي (`UV Index`) من أقمار CERES FLASHFlux.
2. **تغطية شبكية عالمية متصلة 100% (بدون أي فجوات):**
   - شبكة خلايا متصلة ($0.5^\circ \times 0.625^\circ$) تغطي كافة الصحاري والبحار والمحيطات والمناطق غير المأهولة دون أي خلايا فارغة.
3. **درجات الحرارة والخصائص الحرارية:**
   - درجات حرارة الهواء على ارتفاع مترين (المتوسط، العظمى، الصغرى، والمدى الحراري اليومي).
   - حرارة جلد سطح الأرض الإشعاعية الفضائية (`TS / Land Surface Temperature`).
4. **الرطوبة وحركة الرياح:**
   - نقطة الندى والرطوبة النسبية على ارتفاع مترين، والضغط السطحي.
   - سرعة الرياح على ارتفاعات متعددة (2 متر، 10 أمتار، و 50 متراً) واتجاه الرياح.
5. **الأمطار والسحب:**
   - معدل الهطول المطري اليومي المصحح إحصائياً بالمليمتر/يوم.
   - نسبة الغطاء السحابي الكلي (%).

## 4. ما لا يستطيع هذا المصدر توفيره (المحددات والقيود العلمية)
1. **لا يوفر بيانات تاريخية قبل عام 1981:**
   - السلسلة الزمنية تبدأ بدقة في **1 يناير 1981**؛ وبالتالي لا تتوفر أي بيانات للفترات السابقة (1901 إلى 1980).
2. **لا يوفر هبات الرياح اللحظية القصوى (Wind Gusts):**
   - يوفر متوسط سرعة الرياح الساعية واليومية فقط، ولا يسجل الذروة اللحظية لهبات الرياح العاصفة.
3. **لا يوفر ضغط مستوى سطح البحر (PSL) بصورة مباشرة:**
   - يوفر الضغط الجوي السطحي (`PS`) عند منسوب تضاريس النموذج، ويتطلب حساب ضغط مستوى البحر بمعادلة هيبسومترية.
4. **لا يوفر مقاطع رطوبة وحرارة التربة بالأعماق المتعددة:**
   - لا يحتوي على قياسات هيدرولوجيا التربة الرأسية (0-255 سم).
5. **لا يعكس التضاريس الجبلية المعقدة وفروق الارتفاع الدقيقة:**
   - نظراً لأن أبعاد الخلية تبلغ حوالي $50 \times 60$ كم، فإن الفوارق المناخية الدقيقة في الأودية الجبلية الضيقة أو السواحل المتقطعة تصبح ممهدة ولا تظهر بتفاصيلها الطبوغرافية الدقيقة.
6. **لا يعمل بالرصد اللحظي لنفس اليوم (Real-Time):**
   - تتأخر البيانات من يومين إلى 4 أيام عن التاريخ الحالي لإجراء عمليات المعالجة الفضائية وتدقيق الجودة.
