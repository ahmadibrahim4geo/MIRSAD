أضف صناديق Point وWeather Stations وGrid Raster كلًا على حدة. افتح Item Description/عرض المساعدة للأداة لقراءة ملخصها، واستخدم الدليل الكامل المحلي. ملفات XML مرتبطة باسم Toolbox والأداة؛ يجب توزيعها مع ملفات .pyt.

مسار المعالجة القديم يدعم Python 2.7 في ArcMap وPython 3 في Pro. لا تثبّت Qt في Python الخاص بـArcGIS لمجرد فتح الدليل. استخدم ملف HTML أو شغّل عارض Desktop كعملية مستقلة. من Python الخاص بالأداة: from mirsad_core.help_viewer import open_help; open_help("tool-stations", "ar").

التحقق الأصلي موثق لـPro 3.6. لم يكتمل تحقق ArcMap الأصلي في دفعة dev7؛ نجاح اختبارات Python 2.7 لا يحل محله. الفروق المتبقية في مخططات المخرجات وخيارات الراستر المتقدمة معلنة.
