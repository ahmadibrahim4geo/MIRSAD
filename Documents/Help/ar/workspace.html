• قائمة الأدوات ومحتويات الخريطة: الأدوات الرئيسية، الطبقات، الجداول والنتائج. انقر بزر الفأرة الأيمن على الطبقة لعرض نطاقها أو جدولها أو خصائصها وإزالتها من العرض. إزالة طبقة عرض لا تحذف ملفها.
  • التابات الوسطى: الخريطة، الجدول، المهام، بيانات المدخل، عن مرصاد، ومعاينة أطلس PDF. استخدم أسهم شريط التابات إذا لم تتسع النافذة لها كلها.
  • لوحة الأداة: المدخلات والمناخ والراستر والمخرجات. اسحب الفواصل لتغيير العرض؛ تُحفظ هندسة النافذة وترتيب اللوحات. من قائمة التطبيق يمكن إظهار اللوحات أو استعادة ترتيبها.

اسحب الخريطة للتحريك، واستخدم عجلة الفأرة أو +/− للتكبير. مجموعة التنقل تضم عرض نطاق البيانات والعالم. أيقونة الدبوس تُفعّل إضافة نقطة؛ انقر على الخريطة وأكمل بيانات النقطة، أو استخدم Esc للإلغاء. إحداثيات القراءة WGS84؛ إسقاط عرض البلاطات EPSG:3857، وهو مستقل عن إسقاط مخرجات التحليل.

أيقونة الطبقات الصغيرة تفتح لوحة الخلفيات: صور Esri بالأسماء أو بدونها، الشوارع، الطبوغرافية، الرمادي الفاتح والداكن، OpenStreetMap، أو بدون خلفية. توضح اللوحة الاختيار الحالي ومصدره. اختيار خلفية أو النقر خارج اللوحة أو زر الإغلاق أو Esc يغلقها؛ فقدان التركيز وحده أثناء تصوير الشاشة لا يغلقها. الصور المصغرة توضح النمط وليست قياسات أو تنزيلات إضافية.

مصدر الخلفية يظهر أسفل الخريطة. الخلفيات تحتاج إنترنت لتحميل البلاطات غير المخزنة مؤقتًا؛ عرض النقاط المحلية يعمل بدونها. اختيار Basemap لا يغير Provider المناخي. لا توجد خلفيات Google/Azure التي تحتاج API key. يتبع إطار البرنامج الثيم الفاتح/الداكن؛ ألوان الخريطة نفسها تتبع الخلفية المختارة.
