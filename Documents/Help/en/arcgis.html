Add Point, Weather Stations and Grid Raster toolboxes separately. Use Item Description/View Help to read a tool summary and follow the full local manual. Toolbox/tool XML metadata are associated by filename and travel with the .pyt files.

The legacy runtime supports ArcMap Python 2.7 and Pro Python 3. Help requires no Qt installation in ArcGIS Python: use local HTML or launch Desktop help in a separate process. From toolbox Python: from utils.help_viewer import open_help; open_help("tool-stations", "en").

Native verification is recorded for Pro 3.6. Native ArcMap acceptance remained unconfirmed in dev7; Python 2.7 tests are separate evidence. Remaining output-schema and advanced-raster differences are documented.
