الملف/المكانوظيفته
Project.gdb وProject.gpkgنفس السجلات المحسوبة وهندساتها ومفاتيحها الثابتة في FileGDB وGeoPackage، مع إعادة القراءة للتحقق.
ملف Excel لكل عنصرData للبيانات الرئيسية؛ Month للحقول الشهرية؛ Source_Data للمصادر؛ Daily عند التفعيل. يوجد أيضًا تصدير لمواقع Stations.
Years داخل مجلد العنصرملفات إضافية لكل سنة عند الطلب، مع إعدادات المعالجة نفسها؛ هذا لا يحول نقص السنة إلى اكتمال.
Raw_Dataاستجابات المصدر والأعلام ومصادر القيم وملخصات الطلبات وتدقيق التقدير الشهري في Hybrid.
Atlas ومخرجات الراسترGeoTIFF والراستر المصنف والأطلس PDF وتقارير التحقق بحسب الخيارات.
manifest.jsonحالة التشغيل والإعدادات والمخرجات والبصمات والأخطاء؛ المرجع لتحديد النجاح الكامل أو الجزئي.

Daily في Desktop جدول طويل: Station_Key، Station_ID، Station_Name، Date، Variable، Unit، Value؛ لا تفترض أنه مطابق لترتيب الجدول العريض في Toolbox. الحقول الإنجليزية محفوظة مع واجهة محلية. اقرأ Status وError_Msg وCoverage_Fraction وValid_Days/Expected_Days أو Valid_Months/Expected_Months. NULL يعني مفقودًا وليس صفرًا.

Complete يعني اكتمال المخرجات المطلوبة وفق الفحوص. Partial يعني وجود نتائج محفوظة مع نواقص/فشل بعض المراحل؛ افتح السجل. NO_DATA يصف نقص بيانات المصدر، وقد توجد تقديرات شهرية موثقة؛ اقرأها مع حقول Gap Fill. INSUFFICIENT_HISTORY يخص طول التاريخ العلمي. نجاح GeoPackage لا يخفي فشل GDB، وقد تنجح الجداول رغم فشل الراستر. Excel هو المخرج الجدولي المعتاد؛ راجع أي بديل CSV صريح بدل افتراض وجود ملف Excel.

تفسير أعمدة التعريف والتغطية وصفوف Daily في Desktop

Data وMonth: الصف سجل نقطة أو محطة، والأعمدة المناخية تحمل الإحصاءات الموضحة في دليل أسماء الحقول وصفحات العناصر. عند التصدير لكل سنة تخص القيم السنة المعنية. Source_Data يشرح المصدر والتغطية؛ لا تفترض أن كل صف فيه رصد يومي مستقل. قد يختلف ترتيب الحقول وأسماء التعريف في Toolbox؛ احتفظ بالمفاتيح الأصلية ولا تعتمد رقم الصف للربط.

العمودمعناه وطريقة قراءته
Station_Key / Station_ID / WBAN / Station_Nameمفتاح ثابت للسجل / معرف المحطة USAF أو معرف النقطة / معرف WBAN / الاسم. المعرفات نصية تحفظ الأصفار البادئة؛ Station_ID وحده ليس مفتاحًا فريدًا كافيًا للمحطات.
Point_Lat / Point_Lon / Elevation_mخط العرض وخط الطول الجغرافيان بالدرجات في WGS 84، والارتفاع بالمتر. الإحداثيات الوصفية ليست بالضرورة إحداثيات هندسة الطبقة المسقطة.
Country / Source_Country / Coordinate_QAاسم العرض للدولة / كود الدولة الأصلي من المصدر / حالة تدقيق الإحداثيات. مطابقة الكتالوج لا تعني تحققًا ميدانيًا.
Point_Type / Input_Source / Sourceنوع النقطة / مصدر مواقع المدخلات / مصدر البيانات المناخية. مصدر الموقع قد يختلف عن مزود القيم المناخية.
Data_Start / Data_End / Measurement_Unitحدود فترة التشغيل المسجلة ووحدة العنصر؛ لا تثبت اكتمال الأيام داخل الفترة. اقرأ وحدة كل عمود في مرجعه، خصوصًا السرعة والاتجاه أو المتوسط اليومي وإجمالي الطاقة.
Valid_Days / Expected_Daysعدد الأيام ذات مدخلات العنصر المطلوبة الصالحة / عدد الأيام المطلوبة شاملًا البداية والنهاية؛ يستخدمان للمسار اليومي. لا يمثلان عدد المحطات.
Valid_Months / Expected_Monthsعدد الشهور التي تحقق تغطية المدخلات والجودة كاملة / عدد الشهور المطلوبة في المسار الشهري الأصلي. في هذا المسار يكون عدادا الأيام NULL.
Coverage_Fractionكسر تغطية من 0 إلى 1، وليس نسبة من 0 إلى 100: في اليومي الأيام الصالحة ÷ المطلوبة؛ وفي الشهري الأصلي متوسط تغطيات الشهور المطلوبة، مع مراعاة أضعف متغير مطلوب داخل الشهر. مثلًا 0.8 = 80%.
Status / Error_Msgحالة سجل النقطة للعنصر وشرح النقص أو الخطأ؛ لا يكفي وجود قيمة مناخية للحكم باكتمال السجل. حالة السجل منفصلة عن حالة اكتمال المشروع في manifest.
Gap_Fill_Method / Source_Temporal_Resolutionطريقة تعويض الفجوات المسجلة / الدقة الزمنية الأصلية، مثل شهري أو مركب. التقدير الشهري لا يتحول إلى يوم رصد أصلي.
T_Period_Mean / R_Period_Totalمتوسط حرارة الأيام الصالحة داخل الفترة اليومية المطلوبة / مجموع مطر الفترة اليومية عند اكتمال أيامها. قد تكون الفترة جزءًا من سنة؛ هذان ليسا بديلين تلقائيين عن المتوسطات المناخية السنوية.
Date / Variable / Unit / Valueفي Daily: تاريخ اليوم / كود المتغير / وحدة هذه القيمة / القيمة نفسها. مثال: صف T2M وقيمة 20 بوحدة °C يعني حرارة تلك النقطة في ذلك اليوم، وليس المتوسط السنوي. تكرار النقطة في أيام أو متغيرات مختلفة متوقع.
