1. Open Point Climate Atlas Generator with an input point layer, or choose Offline with calculated point layers containing numeric fields.
  2. Check CRS, identities and coordinates. Desktop additionally supports tabular X/Y mapping and map-based point entry.
  3. Select provider, modules, period and units. Gridded products accept arbitrary points; NOAA requires actual station identity, and GHCN requires explicit GHCN_ID in its supported input path.
  4. Download Only keeps point data and tables. To create surfaces configure interpolation, cell size, CRS and mask; see rasters.
  5. Run and inspect status, coverage, actual source and outputs. Missing rainfall is not zero.
