ابدأ من هناGet started

طريقتان لتشغيل مرصاد.Two ways to run MIRSAD.

MIRSAD Desktop Windows x64

  1. نزّل مثبت التطويرDownload the preview installer

    راجع تفاصيل الإصدار وبصمة SHA-256. هذه نسخة تطوير، وليست إصدار stable معتمدًا.Read release details and SHA-256 checksums. This is a development preview, not an approved stable release.

  2. ثبّت التطبيق وافتحهInstall and launch

    التبعيات ودليل المحطات والمساعدة مرفقة؛ لا تحتاج ArcGIS أو Python منفصلًا.Dependencies, station catalogue and help are bundled; no ArcGIS or separate Python is required.

  3. اختر الأداة ومدخلاتهاChoose a tool and its inputs

    حدد المصدر والفترة والعناصر ومسار الإخراج. حفظ المشروعات خارج مجلد التثبيت يحافظ على فصل العمل عن التطبيق.Set source, interval, modules and output directory. Keep user projects outside the installation folder.

ArcGIS Pro / ArcMap

  1. نزّل المستودع كاملًاDownload the whole repository

    فك الحزمة مع الحفاظ على هيكل المجلدات؛ ملفات التول بوكس تعتمد على الملفات المساعدة المجاورة.Extract and preserve the directory structure; toolboxes depend on sibling support resources.

  2. أضف التول بوكس من مجلد ToolboxesAdd a toolbox from Toolboxes/

    من Catalog أو ArcToolbox اختر ملف النقاط أو المحطات أو الشبكة الإقليمية.In Catalog or ArcToolbox, choose the point, station or regional grid toolbox.

  3. راجع متطلبات بيئة ArcGISCheck the ArcGIS environment

    المسارات تراعي Python 2.7 و3؛ الأدوات المكانية قد تحتاج الترخيص المناسب. تحقق المعاملات في Pro لا يعادل اختبار المعالجة الأصلي في ArcMap.Compatibility paths preserve Python 2.7 and 3; spatial operations can require the appropriate license. Pro parameter checks do not establish native ArcMap processing acceptance.
