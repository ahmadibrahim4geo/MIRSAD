# مرجع تصميم MIRSAD Desktop

افتح `MIRSAD-Desktop-Concept.html` مباشرة في المتصفح. الملف مستقل: الشعار والأيقونات وبيانات العرض وCSS وJavaScript مضمّنة؛ لا يحتاج اتصالًا أو تثبيت مكتبات. حجمه نحو 1.5 ميجابايت.

## نص جاهز لتسليم التصميم

> استخدم ملف `MIRSAD-Desktop-Concept.html` كمرجع بصري وتفاعلي لتطوير واجهة برنامج MIRSAD Desktop الحالي. نفّذ التصميم بـPySide6 واربطه بالخدمات الفعلية الموجودة، مع الحفاظ على هوية مرصاد وبيانات المطور والعربية والإنجليزية والمظهرين الفاتح والداكن. اقرأ تعليمات AGENTS.md والخطة الرئيسية ومراجعة المنهجية أولًا. طبّق البحث والتحديد الثابت للمحطات ونقاط المستخدم وإعدادات المصدر والفترة والعناصر والراستر والمخرجات وسجل المهام كما يوضح النموذج. استبدل محاكاة التنزيل والتصدير بعمل حقيقي في الخلفية مع الإلغاء والأخطاء والتغطية والمصدر. حافظ على القيم المفقودة والمعرفات النصية والبيانات الخام. صدّر Excel وFileGDB وGeoPackage وتحقق من كل مخرج مستقلًا. لا تعرض وظيفة غير منفذة كزر يعمل، ولا تعتبر النموذج إثباتًا لصحة الحسابات. استخدم مشروع Desktop الحالي، واختبر الواجهة الأصلية، وحدّث وثائق التنفيذ. ابنِ development فقط؛ لا ترقِّ stable دون موافقتي الصريحة على المرشح.

يمكن تنزيل تعليمات أكثر تفصيلًا من زر «تنزيل تعليمات المطور» في شاشة الإعدادات داخل الملف، وتنزيل خطة الإعدادات من زر «حفظ الخطة».

## نطاق المقترح

- محطات وخريطة: بحث وفرز وصفحات وتحديد ثابت بالمفتاح، وتحديد منفصل للصفحة أو نتائج البحث، واختيار نقاط من الخريطة وتكبير العرض.
- مناخ: NASA POWER وOpen-Meteo ERA5، فترة زمنية، 19 تعريف عنصر مأخوذة من سجل الكود، وإتاحة المصدر وفق المتغيرات التي ينفذها الموصل الحالي.
- مدخلات: إضافة نقاط يدوية والتحقق من الإحداثيات والمعرف، وعرض مسار استيراد الملفات المقترح. خدمات استيراد Excel/GIS غير منفذة في HTML.
- راستر وأطلس: إعدادات طرق الكود الحالي، دون حساب استيفاء أو اختراع قيم مناخية.
- مخرجات: اختيار Excel وGDB وGeoPackage، وخيارات اليومي والسنوي، ومحاكاة قابلة للإلغاء ونتيجة جزئية عند فشل GDB.
- إعدادات وسجل: العربية/الإنجليزية، فاتح/داكن، هوية المشروع والمطور، مصدر الكتالوج، دليل التنفيذ، حفظ/فتح خطة JSON، وتنزيل سجل التجربة.

## أصل البيانات وحدودها

أُخذت 86 سجلاً حيث `country='EG'` كما هي من `assets/stations.sqlite` المضمّنة في Desktop بوضع القراءة فقط، مع إصدار وبصمة `assets/catalogue_manifest.json`: الإصدار `2026.10.17.2`، و28,066 سجلًا عالميًا. تُحفظ أسماء المواقع وUSAF وWBAN والمفاتيح والإحداثيات؛ لم تُصحح سجلات أو ملفات مصدرية ضمن عمل التصميم. تسمية مجموعة مصر تتبع الكتالوج الحالي وليست تدقيقًا مستقلًا لتصنيف الدول. حالة «مطابق للمرجع» تعكس حقل QA الموجود، وليست تحققًا ميدانيًا.

تعريفات العناصر وتبعياتها وإتاحة Open-Meteo مأخوذة من `src/mirsad_desktop/registry.py`. وجود تعريف في السجل لا يثبت اكتمال اختبارات التكافؤ العلمي. لقطة التصميم ثابتة بتاريخ 17 أكتوبر 2026، وليست سجلًا يتحدث آليًا مع تغييرات التطبيق.

خلفية الخريطة رسم تخطيطي توضيحي؛ ليست حدودًا جغرافية أو طبقة GIS. المواقع تُرسم من إحداثيات الكتالوج بإسقاط خطي للعرض فقط. نقاط خارج نطاق العرض المتمركز حول مصر تبقى في الجدول وخطة الإعدادات. في التطبيق الفعلي يُستخدم مكوّن الخرائط الأصلي مع نسب مصادر الخلفيات المطلوبة.

لا ينزّل HTML بيانات مناخية ولا ينتج Excel أو GIS أو Raster. حالات التقدم والنجاح والفشل موسومة بأنها محاكاة. الملفات الحقيقية التي يمكن تنزيلها من النموذج هي خطة JSON ودليل Markdown وسجل نصي فقط. تبقى إعدادات الجلسة في الذاكرة؛ احفظ خطة JSON وأعد فتحها لحفظ عملك بين الجلسات.

هذا تسليم تصميم محلي، وليس إصدار برنامج جديدًا. لم تُعدّل ملفات الأدوات أو البيانات الأصلية أو ملفات تشغيل development/stable.

## التحقق المنفذ

فُحصت الواجهة في المتصفح عبر خادم محلي: البحث والترتيب مع ثبات التحديد، تغير إتاحة العناصر إلى 17 من 19 عند اختيار Open-Meteo، إضافة نقطة يدوية، إلغاء المحاكاة، وإظهار فشل GDB مستقلًا عن نجاح GPKG. جُرّب تبديل اللغة وتنزيل خطة JSON ثم إعادة فتحها بنجاح. لم تظهر أخطاء أو تحذيرات في سجل JavaScript أثناء هذه التجربة. لم يحدث تجاوز أفقي للصفحة عند اختبار عرضي 390 و1440 بكسل. صورة سطح المكتب في `MIRSAD-Desktop-Preview.jpg`.

الفحص البنيوي اجتاز تدقيق صياغة JavaScript، وفرادة 99 معرّف HTML، وعدم وجود أصول تشغيل خارجية، والمطابقة الحرفية لسجلات العرض الـ86 مع لقطة SQLite. لم تُجرَ اختبارات المحرك العلمي لأن هذا التغيير يقتصر على مرجع التصميم. فتح بروتوكول `file://` عبر متصفح الأتمتة غير مسموح بسياسة المتصفح؛ لذا كان الاختبار المرئي عبر HTTP محلي، ولا يُدّعى اختبار الفتح المباشر آليًا.
