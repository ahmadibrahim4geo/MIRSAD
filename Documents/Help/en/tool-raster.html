1. Select the Download AOI and final clip mask. Check the Toolbox Final Clip requirement in the parameter reference; Desktop allows a separate study mask.
  2. Implemented regional products are NASA POWER, CHIRPS and CHELSA. TerraClimate and MODIS currently use point adapters, not regional extraction here.
  3. Choose complete months and source-supported modules; CHIRPS provides monthly precipitation. CHIRPS/CHELSA rainfall totals are not multiplied by days.
  4. NASA uses monthly regional-grid download; CHIRPS/CHELSA read original cell centres inside the polygon. Native source resolution differs from interpolation pixel size.
  5. Set suitable metric CRS, cell size and method, then inspect point/table/raster outputs and warnings.
