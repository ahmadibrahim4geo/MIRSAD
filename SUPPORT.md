# Help and support / المساعدة والدعم

## Quick ways to participate / طرق المشاركة السريعة

- **General feedback / رأيك وتجربتك:** [Share feedback](https://github.com/ahmadibrahim4geo/MIRSAD/issues/new?template=feedback.yml)
- **Bugs / الأعطال:** [Report a bug](https://github.com/ahmadibrahim4geo/MIRSAD/issues/new?template=bug_report.yml)
- **Questions / الأسئلة:** [Ask for help](https://github.com/ahmadibrahim4geo/MIRSAD/issues/new?template=question.yml)
- **Feature requests / المقترحات:** [Request a feature](https://github.com/ahmadibrahim4geo/MIRSAD/issues/new?template=feature_request.yml)
- **Scientific or documentation corrections / التصحيحات العلمية أو الدليل:** [Documentation issue](https://github.com/ahmadibrahim4geo/MIRSAD/issues/new?template=documentation.yml)
- **Leave a short comment / تعليق بسيط:** [Welcome community thread](https://github.com/ahmadibrahim4geo/MIRSAD/issues/1)

Anyone with a GitHub account can share feedback or ask questions, subject to GitHub's participation settings. A reproducible bug report helps development, but no code expertise is required for general feedback. If you received an invitation by email, you can also reply to that email with your comments. Please do not attach credentials or private data.

نرحب برأي الباحث أو الطالب أو المستخدم حتى لو لم يكن مبرمجًا، وحتى لو لم يجرّب كل أدوات مرصاد. يمكنك تقديم ملاحظة مختصرة في الموضوع الترحيبي، أو فتح نموذج أعطال أو مقترحات. تتطلب الكتابة على GitHub حسابًا؛ وإذا وصلتك دعوة بالبريد الإلكتروني فيمكنك الرد عليها بملاحظاتك. يُرجى عدم مشاركة أي بيانات خاصة أو كلمات مرور.

Start with the offline [Arabic manual](Help/MIRSAD_Help_AR.html), [English manual](Help/MIRSAD_Help_EN.html), or Windows CHM files in `Help/`. Download the whole repository ZIP for local use; GitHub's file view does not execute the interactive HTML manual. The same guide opens through Help/F1 in Desktop.

Use the repository's issue templates for a reproducible bug, a feature idea, or documentation corrections. Include the development version, host (ArcMap/Pro/Desktop), source, period, element and a small sanitized example. Report expected and actual values and their units. Do not attach credentials. A licensed native ArcGIS run or authenticated source download may require a separate environment that contributors do not have.

ابدأ بالدليل العربي أو الإنجليزي وملفات CHM المحلية. استخدم قوالب Issues للأعطال والأفكار وتصحيح التوثيق، مع الإصدار والمضيف والمصدر والفترة والعنصر ومثال صغير منزوع البيانات الحساسة. اذكر المتوقع والفعلي والوحدات. ملفات EXE والمثبت ليست ضمن مصدر Git؛ حالة نشر النسخة الثنائية موضحة في README.
