Spatial Reference Properties: Favorites holds systems you explicitly bookmark across sessions. Layers groups the actual source CRS of loaded spatial layers and lists the layers using each definition; undefined systems remain Unknown. Geographic Coordinate System uses the continent folders, and Projected Coordinate System retains the native Esri hierarchy. For example: UTM → WGS 1984 → Northern Hemisphere or Southern Hemisphere. UTM also contains continent, BLM and other groups from the Pro 3.6 reference. Search names, codes or folder names; clearing search restores previously expanded branches. Show selected reveals the selected path; Details exposes datum, units and projection parameters. Including additional Esri definitions never replaces this tree: definitions absent from the native snapshot use an explicitly separate branch because the public source does not declare their Pro folder paths. Selecting a layer CRS changes this choice, without rewriting its original dataset.

Implemented methods are IDW, Nearest, Linear TIN, Spline (thin plate), Ordinary Kriging (exponential). IDW exposes power and neighbour count; this does not mean every advanced ArcGIS Pro option has been migrated. Inspect point distribution, values and NULLs before interpolation. Use a study clipping mask; a rectangular raster extent is not an administrative boundary.

Output CRS can be a valid geographic/projected system. Spatial processing needs a projected CRS in meters and a meter-based cell size; EPSG:4326 degrees are not metric distance coordinates. Use a suitable local projection, such as an appropriate UTM zone for a small area. The CRS picker has Geographic/Projected trees, code/name search, the embedded ArcGIS Pro 3.6 taxonomy and a newer definitions option. A valid definition does not certify every datum transformation's accuracy or required grid availability.

Annual/seasonal field rasters, optional monthly rasters and a PDF atlas can be generated. Optional classification offers Jenks, Equal Interval or Quantile, with 2–16 requested classes. Classified rasters use class 1 for the highest values and 0 for NoData; fewer distinct values can reduce actual class count. Leave-one-out validation is not proof of field accuracy.

The default raster cap is one million cells; local Kriging is capped at 250,000. Increase cell size or reduce the study area if a resource limit appears. Smaller output cells do not add new observation detail. Specialized wind vectors/contours and some advanced spline, kriging and search options are not all implemented or numerically certified against ArcGIS.
