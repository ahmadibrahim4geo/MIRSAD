MIRSAD Desktop is an independent Windows application for climate atlases from station locations, user points or a native regional climate grid. Outputs include Excel, GIS databases, rasters and PDF atlases. ArcGIS and a separate Python installation are not required. This manual describes implemented development version {{VERSION}}, rather than planned features.

  1. Select a geoprocessing tool.
  2. Configure Inputs → Climate → Raster → Outputs.
  3. Start with a small area, a complete period and Temperature/Precipitation to verify your inputs.
  4. Choose Run Tool; inspect task status, the output directory and manifest.json.

Export Points exports selected locations only; it does not download climate data or automatically create an atlas. Each tool keeps a separate working draft and point selection during the session. Store projects outside the application directory. Use a new project name for each run; existing projects are not silently overwritten.
