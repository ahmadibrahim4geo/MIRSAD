# معادلات الحرارة المحسوسة (Heat Index) — مرجع ثنائي اللغة
# Felt-Temperature Equations Reference (bilingual)

> المصدر الوحيد للمعادلات: `POWER_Climate_Atlas_Generator_10_8.pyt`
> (single source of truth). القيم المحسوبة بالأسفل مُتحقق منها بتنفيذ الكود مباشرة.

المدخلات لجميع المعادلات: `T` حرارة الهواء (°C) عند 2م، `RH` الرطوبة النسبية (%).
القيم المفقودة (`None`/`-999`/NaN) تُرجع `None` دائماً. `RH` تُقصّر على `[0, 100]`.

---

## 1. روتفوش Rothfusz (NWS) — الصيف والربيع والخريف والسنوي

تحويل داخلي: `Tf = T×9/5 + 32` (فهرنهايت)، والناتج يُحوَّل لمئوية في النهاية.

- إذا `Tf < 80°F` (أي `T < 26.7°C`): الناتج = `T` نفسها (passthrough).
- غير ذلك، كثير الحدود 9 حدود:

```
HI = -42.379 + 2.04901523·Tf + 10.14333127·RH − 0.22475541·Tf·RH
     − 0.00683783·Tf² − 0.05481717·RH² + 0.00122874·Tf²·RH
     + 0.00085282·Tf·RH² − 0.00000199·Tf²·RH²
```

تعديلان طرفيان (NWS):
- جفاف شديد: إذا `RH < 13` و`80 ≤ Tf ≤ 112`: `HI −= ((13−RH)/4)·√((17−|Tf−95|)/17)`
- رطوبة عالية: إذا `RH > 85` و`80 ≤ Tf ≤ 87`: `HI += ((RH−85)/10)·((87−Tf)/5)`

مثال مُتحقق: `T=38, RH=45` ← `HI = 45.86°C` | `T=20, RH=50` ← `20.0°C` (passthrough).

## 2. الهيوميدكس Humidex (كندا) — الشتاء فقط

```
e = 6.112 × 10^((7.5·T)/(237.7+T)) × (RH/100)   [ضغط البخار hPa]
Humidex = T + (5/9)·(e − 10)
```

مثال مُتحقق: `T=12, RH=70` ← `11.9°C`.

## 3. البصيلة الرطبة Stull (2011) + ‏WBGT‏ الظلي (ISO 7243 مبسط)

```
Tw = T·atan(0.151977·√(RH+8.313659)) + atan(T+RH) − atan(RH−1.676331)
     + 0.00391838·RH^1.5·atan(0.023101·RH) − 4.686035
WBGT_shade = 0.7·Tw + 0.3·T     (بدون حمل شمسي، بدون تصحيح رياح Liljegren)
```

مثال مُتحقق: `T=32, RH=60` ← `Tw = 25.79` ← `WBGT = 27.65°C`.
