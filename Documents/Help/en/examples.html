A. A one-year station atlas

  1. Select the station tool, region/country and at least two required stations.
  2. Choose Hybrid, 2024-01-01 through 2024-12-31, Temperature and Precipitation.
  3. Start with the data workflow, new project name and output directory; run.
  4. Inspect Coverage and Raw_Data. Then enable the full pipeline, choose a suitable metric CRS, study mask and cell size for rasters.

B. Excel points in UTM

  1. Keep ID as text; prepare Name, Easting, Northing and a header row.
  2. Import and map X=Easting, Y=Northing and the correct UTM CRS; do not assign WGS84 merely because the map displays it.
  3. Select points. Choose NASA/Open-Meteo to download, or existing numeric attributes for interpolation without downloading.

C. A NASA regional grid atlas

  1. Select Grid Raster and a small download AOI plus study mask.
  2. Request a whole month, such as 2024-01-01 through 2024-01-31.
  3. Select modules, enable the full pipeline if needed, run and inspect native cells/gaps. No Daily records are expected.
