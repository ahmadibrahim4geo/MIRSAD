MIRSAD Desktop is an independent 64-bit Windows application. Use the approved installer when an approved release is available, or the complete development folder. Keep _internal beside MIRSAD.exe; the EXE alone is incomplete. Store projects outside the application directory.

Add the three .pyt files to the ArcGIS Pro or ArcMap Catalog, keeping utils and repository dependencies beside them. ArcGIS spatial operations require the appropriate Spatial Analyst licence. Desktop does not require ArcGIS.

MIRSAD.exe --user-guide --language en --help-topic tool-points opens help alone. Without Desktop, open Help/index.html for offline contents, search, bookmarks and printing.
