# MIRSAD visual identity

Approved by the project owner on October 16, 2026: **proposal 2**, the folded map / M symbol with a golden sun dot and the bilingual `مِرصاد / MIRSAD` wordmark.

The complete version with two full-width name lines was subsequently approved on the same date: Arabic first, then English. This is the primary repository and website logo.

- `mirsad-logo-full.png`: approved complete logo on white, 1774 × 887, with the Arabic and English full names. The first element of the root README and the website hero image. Generated with the built-in `image_gen` tool from the approved proposal.
- `mirsad-wordmark.png`: compact transparent horizontal wordmark for light backgrounds, retained for uses that do not have room for the full-name lines.
- `mirsad-icon-dark.svg`: clean geometric icon for dark backgrounds; white and turquoise map panels with the gold dot. Used in the navigation bar.
- `mirsad-favicon.svg`: the same icon on a navy rounded square for browser tabs.
- `mirsad_logo.jpg`: previous emblem, retained as a historical asset; no longer referenced by the landing page.

Colors: navy `#08273D`, turquoise `#12B8C8`, gold `#E8AD43`, white `#FFFFFF`. Keep the complete horizontal wordmark visible without circular cropping. The compact icons are SVG implementations of the approved folded-map geometry; they need no external fonts or scripts.

## Approved full names

Arabic: **قاعدة بيانات الأطلس المكاني لإعادة التحليل المتكامل للأرصاد الجوية**

English: **Meteorological Integrated Reanalysis Spatial Atlas Database**

The word is **Spatial**, not Special. Full names belong beneath the entire logo, each on its own line, with Arabic above English. Keep the compact symbol for the navigation bar and favicon so the long names remain readable in the main logo.
