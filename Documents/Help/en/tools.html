ToolWhen to use it
Ground Weather Stations Climate Atlas GeneratorChoose catalogue station locations by region, country and search, then explicitly select stations. NOAA Only, ERA5 Standalone, station/point Hybrid, legacy Open-Meteo and NASA POWER are available.
Spatial Climate Atlas GeneratorUse your coordinates: import a file, enter coordinates, place points on the map, or generate a point grid inside a polygon. Download climate at those points or interpolate existing numeric attributes without a download.
Grid Raster Climate AtlasRead the implemented NASA POWER, CHIRPS or CHELSA native monthly regional grid. Set the download AOI and optionally a separate study clipping mask. This is not a set of generated point requests, a daily regional workflow or an ERA5 regional download.

Data workflow: calculated climate records, Excel, FileGDB and GeoPackage. Full pipeline: enable atlas output and configure Raster to add interpolation, raster files and the atlas. An accessible Raster tab does not enable raster generation by itself. Existing fields: select imported points with numeric attributes and check the fields to interpolate; this path does not require a provider.

A catalogue location does not guarantee observations for every year. User/generated points do not become NOAA stations merely by location; Hybrid uses reanalysis/POWER when a valid USAF/WBAN observation identity is absent.
