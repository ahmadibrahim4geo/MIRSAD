مرصاد MIRSAD Desktop تطبيق Windows مستقل لإعداد أطلس مناخي من محطات أو نقاط أو شبكة بيانات إقليمية، وإنتاج Excel وقواعد GIS وراستر وأطلس PDF. لا يحتاج ArcGIS أو تثبيت Python على جهاز التشغيل. هذا الدليل يصف وظائف إصدار التطوير {{VERSION}} المتاحة فعلًا؛ وليس قائمة بخصائص مخططة.

  1. اختر الأداة من قائمة أدوات المعالجة.
  2. اضبط المدخلات → المناخ → الراستر → المخرجات.
  3. ابدأ بنطاق صغير وفترة كاملة ودرجة الحرارة والأمطار للتحقق من المدخلات.
  4. اضغط تشغيل الأداة، ثم راجع حالة المهمة ومجلد النتائج وملف manifest.json.

زر تصدير النقاط يصدر مواقع النقاط المختارة فقط؛ لا ينزّل بيانات مناخية ولا ينتج أطلسًا من تلقاء نفسه. لكل أداة مسودة إعدادات ونقاط مستقلة أثناء الجلسة. احتفظ بملفات العمل خارج مجلد البرنامج، واختر اسم مشروع جديد لكل تشغيل؛ لا يُستبدل مشروع موجود بصمت.
