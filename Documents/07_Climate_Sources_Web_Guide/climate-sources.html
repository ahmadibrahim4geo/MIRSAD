الاختيار التلقائي (Auto) يراعي العنصر والفترة كاملة داخل المصدر المختار. الإعداد اليدوي متاح حيث يدعمه المصدر. تصغير خلية راستر الإخراج لا يزيد دقة البيانات الأصلية.Auto considers each variable and the whole interval within the selected source. Manual profiles are available where supported. A smaller output raster cell does not add source detail.

المحطة ليست نوع بياناتLocation does not define data type

المصادر الشبكية تستخرج قيم الخلية عند النقاط أو مواقع المحطات. رصد NOAA يتطلب معرف المحطة الصحيح؛ لا نستبدله بأقرب محطة. البيانات الشهرية لا تتحول إلى رصد يومي.Gridded sources sample a cell at point or station locations. NOAA observations require the correct station ID; no nearest station is substituted. Monthly data does not become daily observations.

تسجيل الدخول وحالة التحققAccounts and verification

CDS يحتاج رمز حساب شخصي، وIMERG يحتاج حساب Earthdata وإذن GES DISC. المساران منفذان؛ التحقق بتنزيل فعلي مسجل الدخول ما زال معلقًا. لا توجد بيانات دخول للمطور داخل البرنامج.CDS needs a personal token; IMERG needs Earthdata and GES DISC authorization. Both adapters are implemented; authenticated end-to-end downloads remain unverified. No developer credentials are bundled.

الاختيار التلقائي يستخدم ERA5-Land للحرارة والرطوبة والندى، وERA5 لبقية المتغيرات المدعومة. للفترة التي تبدأ قبل 1950 يستخدم ERA5 كاملًا. الوضع المستقل لا يستكمل NASA؛ المسار القديم والهجين لهما سياسة معلنة منفصلة. إضافات RHmax/RHmin وVPD وساعات السطوع والرياح ذات ارتفاع القياس المؤكد مدمجة في Desktop وأداتَي Point وStation بالمسار اليومي؛ لا تشمل الشبكة الإقليمية. ملخصات الساعات تشترط 24 ساعة UTC صحيحة؛ counts وعمليات الاشتقاق محفوظة في Excel.Auto uses Land for temperature, RH and dewpoint and ERA5 for other supported variables. An interval beginning before 1950 uses ERA5 throughout. Standalone never supplements NASA; legacy and Hybrid retain explicitly separate policies. New RH extrema, VPD, sunshine and confirmed-height wind options are integrated in Desktop and the Daily Point/Station tools; regional activation is not included. Hourly aggregation requires 24 valid UTC hours; sample counts and operations are exported in Excel.

Monthly filling is separate from daily observations and does not guarantee complete periods.
